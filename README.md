# outbreak-retro-prediction
Pre-registered outbreak mutation/site predictions using only pre-outbreak data, scored
against actual evolution, plus pandemic-response tooling built from the validated scores.
Project 13 of the 13-project open-data computational-biology portfolio.

- GATES_LOCKED.md — success gates locked before any results (standalone first commit)
- PRIOR_ART.md — prior-art sweep and differentiation
- PREREGISTRATION.md — hashed site predictions (committed before outcome data/scoring)
- code/ — pipeline; data/ — manifests + checksums (raw via NCBI/PDB/Nextstrain);
  results/ — scored outputs + figures; tools/ — T1–T4 CLIs; paper/ — manuscript
- MANIFEST.sha256 — byte-locked slice manifest (updated at each push stage)
